# Best Time to Buy and Sell Stock

**LeetCode Problem:** 121  
**Difficulty:** Easy  
**Topic:** Arrays & Strings

## Problem
Find the maximum profit by buying and selling a stock once.

## Approach
1. Store the minimum price seen so far.
2. Calculate profit for each day.
3. Update maximum profit if the current profit is greater.
4. Return the maximum profit.

## Time Complexity
O(n)

## Space Complexity
O(1)

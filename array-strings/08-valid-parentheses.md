# Valid Parentheses

**LeetCode Problem:** 20  
**Difficulty:** Easy  
**Topic:** Stacks

## Problem
Check whether the brackets in a string are valid and properly closed.

## Approach
1. Create a stack.
2. Push opening brackets into the stack.
3. For closing brackets, check the top element.
4. If brackets match, pop the stack.
5. If all brackets match and stack is empty, return true.

## Time Complexity
O(n)

## Space Complexity
O(n)

# Longest Common Prefix

**LeetCode Problem:** 14  
**Difficulty:** Easy  
**Topic:** Arrays & Strings

## Problem
Find the longest common prefix among the given strings.

## Approach
1. Take the first string as the reference.
2. Compare its characters with all other strings.
3. Stop when a character does not match.
4. Return the common prefix.

## Time Complexity
O(n × m)

## Space Complexity
O(1)

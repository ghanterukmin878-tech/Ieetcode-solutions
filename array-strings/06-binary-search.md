# Binary Search

**LeetCode Problem:** 704  
**Difficulty:** Easy  
**Topic:** Arrays & Strings

## Problem
Find the target value in a sorted array and return its index.

## Approach
1. Set left and right pointers.
2. Find the middle index.
3. Compare the middle element with the target.
4. Search the left or right half accordingly.
5. Return -1 if the target is not found.

## Time Complexity
O(log n)

## Space Complexity
O(1)

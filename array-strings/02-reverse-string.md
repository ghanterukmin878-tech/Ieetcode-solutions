# Reverse String

**LeetCode Problem:** 344

**Difficulty:** Easy

**Topic:** Arrays & Strings

## Problem
Reverse the given string by modifying the input array in-place.

## Approach
1. Take two pointers: `left` and `right`.
2. Swap the characters at both positions.
3. Move `left` forward and `right` backward.
4. Continue until both pointers meet.

## Time Complexity
O(n)

## Space Complexity
O(1)
